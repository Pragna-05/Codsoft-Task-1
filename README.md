# Rule-Based Chatbot 🤖

This is a simple rule-based chatbot built using Python.
It responds to user inputs using predefined if-else conditions.

## Features
- Beginner friendly
- No external libraries
- Interactive console chatbot

## How to Run
1. Install Python
2. Run:
   python chatbot.py

## Example
You: tell me a joke  
Bot: Why do programmers prefer dark mode? Because light attracts bugs!
